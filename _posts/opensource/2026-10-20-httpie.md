# [오픈소스 소개] HTTPie: 사람이 읽기 쉬운 커맨드라인 HTTP 클라이언트

- **저장소:** [httpie/cli](https://github.com/httpie/cli) · [httpie.io](https://httpie.io) · [문서](https://httpie.io/docs)
- **라이선스:** BSD 3-Clause
- **언어:** Python
- **현황 (2026-10-20 기준):** GitHub 스타 약 3.9만 개, 최신 릴리스 3.2.4 (2024년 11월)

## 한 줄 요약

**curl보다 쉽고 보기 좋은 터미널용 HTTP 클라이언트**입니다. API를 테스트하고 디버깅할 때 자연스러운 문법으로 요청을 보내고, 응답을 색깔과 줄맞춤이 된 형태로 보여줍니다.

## 주요 기능

- 직관적인 문법
- 응답을 색상과 줄맞춤으로 보기 좋게 출력
- JSON 기본 지원
- 폼 전송과 파일 업로드
- HTTPS, 프록시, 인증
- 커스텀 헤더
- 세션 유지(로그인 상태 등을 저장해 재사용)
- `wget`처럼 파일 다운로드

## 사용 예시

```bash
# 가장 간단한 요청
https httpie.io/hello

# PUT 요청 + 헤더 + JSON 본문
# (key=value는 JSON 필드, Key:Value는 헤더)
http PUT pie.dev/put X-API-Token:123 name=John

# 실제로 보내지 않고 요청 내용만 확인 (offline 모드)
http --offline pie.dev/post hello=offline

# 인증을 붙여 GitHub 이슈에 댓글 달기
http -a USERNAME POST https://api.github.com/repos/httpie/cli/issues/83/comments body='HTTPie is awesome! :heart:'
```

같은 요청을 curl로 쓰면 `-H`, `-d`, JSON 따옴표 처리 등을 직접 해야 하지만, HTTPie는 `name=John`처럼 쓰기만 하면 알아서 JSON으로 만들어줍니다.

## 재미있는 이야기: 사라진 5.4만 개의 별

HTTPie 팀이 실수로 저장소를 잠깐 비공개로 전환했다가, 10년 동안 모은 GitHub 스타 약 **5만 4천 개**가 모두 사라진 일이 있었습니다. 지금의 스타 수는 그 이후 다시 모은 것입니다. 자세한 이야기는 [공식 블로그](https://httpie.io/blog/stardust)에 있습니다.

## 설치

```bash
brew install httpie      # macOS
pip install httpie       # 파이썬 환경
```

다른 설치 방법은 [설치 문서](https://httpie.io/docs#installation)를 참고하세요.

## 이런 분께 추천

- curl 옵션이 매번 헷갈리는 분
- 터미널에서 REST API를 자주 테스트하는 백엔드 개발자
- API 응답을 사람이 읽기 좋게 보고 싶은 분
