# [오픈소스 소개] Lapce: Rust로 만든 초고속 코드 에디터

- **저장소:** [lapce/lapce](https://github.com/lapce/lapce) · [lapce.dev](https://lapce.dev) · [문서](https://docs.lapce.dev/)
- **라이선스:** Apache 2.0
- **언어:** Rust
- **현황 (2026-10-20 기준):** GitHub 스타 약 3.9만 개, 최신 릴리스 v0.4.6 (2026년 1월)

## 한 줄 요약

**순수 Rust로 만든 빠르고 강력한 코드 에디터**입니다. VS Code 같은 편의 기능을 갖추면서도 훨씬 가볍고 빠른 것을 목표로 합니다. 이름은 "랩스(/læps/)"로 읽습니다.

## 왜 빠른가

- **Rust로 작성:** 메모리 관리가 효율적이고 실행 속도가 빠릅니다.
- **Rope 자료구조:** Xi-Editor의 "Rope Science"를 바탕으로, 큰 파일도 빠르게 편집할 수 있게 텍스트를 다룹니다.
- **GPU 렌더링:** [wgpu](https://github.com/gfx-rs/wgpu)로 화면을 그립니다.
- **자체 UI 프레임워크:** UI는 Lapce 팀이 만든 [Floem](https://github.com/lapce/floem)으로 만들었습니다.

## 주요 기능

- **LSP 내장:** 자동 완성, 오류 진단, 코드 액션 같은 지능형 기능을 바로 쓸 수 있습니다.
- **Vim 모드 기본 지원:** Vim 스타일 모달 편집을 켜고 끌 수 있습니다.
- **원격 개발:** VS Code Remote처럼 원격 서버의 코드를 로컬처럼 편집할 수 있습니다.
- **WASI 플러그인:** C, Rust, AssemblyScript 등 WASI로 컴파일되는 언어로 플러그인을 만들 수 있습니다.
- **내장 터미널:** 에디터를 떠나지 않고 명령을 실행할 수 있습니다.

## 설치

Windows, Linux, macOS용 실행 파일을 [릴리스 페이지](https://github.com/lapce/lapce/releases)에서 받거나, [패키지 매니저로 설치](https://github.com/lapce/lapce/blob/master/docs/installing-with-package-manager.md)할 수 있습니다.

## 이런 분께 추천

- VS Code가 무겁게 느껴지는 분
- Vim 키 바인딩을 기본으로 지원하는 현대적인 GUI 에디터를 찾는 분
- Rust 생태계와 고성능 에디터 구조에 관심 있는 분

아직 버전이 0.x대인 만큼, 확장 생태계는 VS Code보다 작다는 점을 고려하세요.
