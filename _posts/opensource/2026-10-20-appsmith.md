# [오픈소스 소개] Appsmith: 관리자 페이지와 사내 도구를 빠르게 만드는 로우코드 플랫폼

- **저장소:** [appsmithorg/appsmith](https://github.com/appsmithorg/appsmith) · [appsmith.com](https://www.appsmith.com) · [문서](https://docs.appsmith.com)
- **라이선스:** Apache 2.0
- **언어:** TypeScript
- **현황 (2026-10-20 기준):** GitHub 스타 약 4.1만 개, 최신 릴리스 v2.5.0 (10월 9일)

## 한 줄 요약

**대시보드, 관리자 페이지, 사내 업무 도구를 드래그 앤 드롭으로 만드는 오픈소스 로우코드 플랫폼**입니다. 25개 이상의 데이터베이스와 어떤 API든 연결할 수 있습니다.

## 무엇을 만들 수 있나

- 관리자 패널(Admin Panel)
- 데이터 대시보드
- 고객 정보를 한곳에 모아 보는 화면(Customer 360)
- IT 자동화, 서비스 관리 도구

UI 컴포넌트를 끌어다 놓고, DB 쿼리나 API 호출 결과를 연결한 뒤, 필요한 부분만 JavaScript로 채우는 방식입니다. 이렇게 하면 사내 도구를 처음부터 개발하는 것보다 훨씬 빠르게 만들고 유지보수할 수 있습니다.

## 시작하는 방법

| 방법 | 설명 |
|---|---|
| [Appsmith Cloud](https://login.appsmith.com/) | 가입만 하면 바로 사용 |
| [Docker](https://docs.appsmith.com/getting-started/setup/installation-guides/docker) | **권장** 셀프 호스팅 방식 |
| [Kubernetes](https://docs.appsmith.com/getting-started/setup/installation-guides/kubernetes) | 대규모 운영 환경 |
| [AWS AMI](https://docs.appsmith.com/getting-started/setup/installation-guides/aws-ami) | AWS에 바로 설치 |

[튜토리얼](https://docs.appsmith.com/getting-started/tutorials)과 [템플릿](https://www.appsmith.com/templates)으로 시작하면 금방 익힐 수 있습니다.

## Appsmith Agents

최근에는 AI 기능인 **Appsmith Agents**도 내놓았습니다. 회사 내부 데이터를 AI 모델에 계속 맥락으로 넣어주기 때문에, 모델을 따로 파인튜닝하거나 복잡한 RAG를 구축하지 않아도 업무에 맞는 질문과 자동화를 설정할 수 있다고 소개합니다. 영업, 고객 지원, 인사 같은 비개발 부서를 겨냥한 기능입니다.

## 이런 분께 추천

- 운영팀이 쓸 관리자 화면을 빨리 만들어야 하는 개발자
- Retool 같은 상용 도구 대신 직접 설치할 수 있는 오픈소스를 찾는 팀
- 사내 데이터가 외부로 나가면 안 되는 환경
