# [오픈소스 소개] Files: Windows를 위한 현대적인 오픈소스 파일 관리자

- **저장소:** [files-community/Files](https://github.com/files-community/Files) · [files.community](https://files.community)
- **라이선스:** MIT
- **언어:** C#
- **현황 (2026-10-20 기준):** GitHub 스타 약 4.6만 개, 최신 릴리스 v4.3 (10월 11일)

## 한 줄 요약

**Windows 기본 탐색기를 대신하는 깔끔한 디자인의 파일 관리자**입니다. "Windows 최고의 파일 관리자"를 목표로 커뮤니티가 공개적으로 개발하고 있습니다.

## 주요 특징

- **강력한 멀티태스킹:** 여러 폴더와 작업을 동시에 다루기 편하게 설계되었습니다.
- **파일 태그:** 파일과 폴더에 태그를 붙여 정리할 수 있습니다.
- **Windows 통합:** Windows의 다양한 기능과 깊게 연동됩니다.
- **직관적인 디자인:** 깔끔하고 이해하기 쉬운 UI

![Files 스크린샷](https://raw.githubusercontent.com/files-community/Files/main/assets/FilesScreenshot.png)

## 설치

- **Microsoft Store**에서 구매하거나, 홈페이지에서 **클래식 설치 파일**을 받아 설치할 수 있습니다.
- 정식 버전과 함께 **프리뷰 버전**을 설치해 새 기능을 먼저 써볼 수도 있습니다.
- 소스에서 직접 빌드하려면 [빌드 가이드](https://files.community/docs/contributing/building-from-source)를 참고하세요.

커뮤니티 후원으로 유지되는 프로젝트라, Microsoft Store 구매나 GitHub 후원으로 지원해 달라고 안내합니다.

## 이런 분께 추천

- Windows 탐색기의 기능과 디자인이 아쉬웠던 분
- macOS Finder처럼 깔끔한 파일 관리자를 Windows에서 쓰고 싶은 분
- 참고로 **Windows 전용**입니다.
