# [기술 소개] '미국판 DeepSeek' Reflection AI의 오픈 모델 Beam

> 원문: [The American DeepSeek Is Here, and It Just Beat Opus 5 on a Viral Test](https://medium.com/the-ai-studio/the-american-deepseek-is-here-and-it-just-beat-opus-5-on-a-viral-test-3588a89eb350) (Pranit Naik, Medium · The AI Studio)
> 이 글은 원문을 한국어로 요약·정리한 것입니다. 수치는 대부분 Reflection AI가 직접 발표한 값입니다.

## 한 줄 요약

미국 스타트업 Reflection AI가 2026년 10월 5일 공개한 오픈 모델 **Beam**은 최강 모델은 아니지만, **적은 연산으로 중국 최신 모델의 한 세대 전 수준**까지 따라왔습니다. 특히 대규모 강화학습 방식이 다음 모델들의 표준이 될 수 있다는 점에서 주목할 만합니다.

## 배경: 왜 '미국판 DeepSeek'인가

- 지난 2년 가까이 내려받아 쓸 수 있는 최고의 오픈 모델은 대부분 중국산(DeepSeek, Qwen, Kimi, GLM, MiniMax 등)이었습니다. 최근 1년 Hugging Face 다운로드의 약 41%가 중국 모델이었습니다.
- 오픈 모델 사용량도 크게 늘었습니다. Vercel AI Gateway에서 오픈 모델 트래픽 비중은 작년 12월 10% 미만에서 8월 56%까지 올라갔습니다.
- 규정이나 정책 때문에 중국 모델을 쓸 수 없는 기업·정부 기관에게는 쓸 만한 미국산 오픈 모델이 마땅치 않았습니다. Beam은 이 빈자리를 노립니다.

## Beam 한눈에 보기

| 항목 | 내용 |
|---|---|
| 개발사 | Reflection AI (뉴욕, 2024년 설립) |
| 크기 | 총 5,010억(501B) 파라미터, 토큰당 약 230억(23B) 활성 |
| 입력 | 텍스트 전용 |
| 강점 | 코딩, 추론, AI 에이전트 |
| 학습 데이터 | 텍스트·코드 23.8조 토큰 |
| 컨텍스트 | 100만 토큰 |
| 추론 강도 조절 | 빠른 응답 ↔ 무거운 작업 전환 가능 |
| 라이선스 | Apache 2.0 (수정·상업적 이용 자유) |
| 상태 | 최종 테스트 및 얼리 액세스 대기 중, 이번 달 전체 가중치 공개 예정 |

**만든 사람들:** Google DeepMind 출신 두 명이 창업했습니다. CEO Misha Laskin은 Gemini의 답변 품질 판별(보상 모델) 작업을, CTO Ioannis Antonoglou는 AlphaGo 개발에 참여했습니다. 두 사람 모두 강화학습 전문가입니다.
원래는 서구권 오픈 모델 위에서 동작하는 코딩 에이전트를 만들려 했지만, 기반으로 삼을 만한 서구권 모델이 없어서 직접 모델을 만들기로 방향을 바꿨습니다. Nvidia와 Sequoia가 투자했고, 6월 기업가치는 250억 달러입니다.
DeepSeek이 "적은 자원으로 많은 성과"를 냈다면, Reflection은 "많은 자원으로 많은 성과"를 내는 쪽입니다.

## Beam의 7가지 특징

### 1. 크지만 중형 모델처럼 동작 (MoE)
**전문가 혼합(Mixture of Experts)** 구조라서 토큰마다 필요한 전문가 블록만 계산에 참여합니다. 지식은 501B 규모로 많지만, 토큰당 계산량은 23B 수준입니다.

### 2. 100만 토큰 컨텍스트
두 종류의 어텐션 층을 번갈아 씁니다.
- 가까운 수백 토큰만 보는 층
- 전체 내용을 압축한 요약을 보는 층

소설을 읽으면서 가끔 챕터 메모를 들춰보는 것과 비슷합니다. 중간 학습 단계에서 긴 코드 저장소와 긴 문서를 집중적으로 학습시켰습니다.

### 3. 1억 번 넘게 연습한 강화학습
- **사전학습:** Nvidia GB300 6,144개로 4주 미만
- **강화학습:** GB300 10,500개로 4주 더 진행했습니다.
  - 실제 과제 시도 1억 회 이상
  - 샌드박스(격리된 코드 실행 환경) 약 13억 개
  - 과제당 최대 25.6만 토큰
- 학습이 끝날 때까지 점수가 계속 오르고 있었습니다. 이 단계에서 흔히 생기는 보상 해킹(채점의 허점을 노리는 것)은 나타나지 않았다고 합니다.

### 4. 장황하면 감점
과제를 완수하면 보상을 받지만, 불필요하게 길게 쓰면 점수가 깎이도록 설계했습니다.
- 초기에는 답이 짧아지면서 점수가 올랐습니다.
- 에이전트 능력이 좋아진 뒤에는 다시 답이 길어졌습니다. 다만 이번에는 늘어난 길이가 실제 성과로 이어졌습니다.

"오래 생각할수록 좋다"는 업계 흐름과 반대되는 접근입니다.

### 5. 부정행위를 막는 채점
과제가 너무 쉽거나 허점이 있으면 학습이 금방 멈췄습니다. 그래서 환경을 더 어렵고 정교하게 다듬어야 했고, 통과한 답변은 별도 심사 모델로 한 번 더 검증했습니다.

### 6. 비동기 학습과 '정책 노후화(policy staleness)' 해결
긴 시도를 하나하나 기다리면 GPU가 놀게 됩니다. 그래서 시도 생성과 모델 업데이트를 동시에 진행했습니다.
이렇게 하면 예전 버전 모델이 만든 데이터로 학습하는 문제(정책 노후화)가 생깁니다. Reflection은 **모든 토큰에 그 토큰을 만든 모델 버전을 붙이고, 오래된 토큰일수록 가중치를 낮춰** 이 문제를 풀었습니다.

| 지표 | 수치 |
|---|---|
| 추론 GPU : 학습 GPU 비율 | 작업량에 따라 약 3.9~5.4 : 1로 동적 조정 |
| 새 가중치 배포 시간 | 중앙값 약 12초 (랙 간 트래픽 75% 감소, 배포 속도 2.2배) |
| 장애 | 71회 발생, 학습 중단 없음, 손실 시간 0.02% |
| 동시 실행 샌드박스 | 최대 17만 개 (생성 요청 10억 건 이상, 90%가 10초 안에 준비) |
| 배치 채움률 | 평균 99.99% |
| 안정적으로 학습 가능했던 데이터 | 최대 107버전 전(약 하루 전) 데이터까지 |

긴 에이전트 과제는 이런 방식이 아니면 학습하기 어렵습니다. 그래서 글쓴이는 이 인프라가 이번 프로젝트의 가장 중요한 기여일 수 있다고 봅니다.

### 7. 가르치지 않은 능력도 스스로 습득
추론, 소프트웨어 엔지니어링, 터미널 작업만 학습했는데 웹 브라우징 능력도 함께 좋아졌습니다. 인터넷이 연결되자 다른 AI에게 도움을 요청하거나 문서·이미지에서 텍스트를 뽑는 도구를 스스로 찾아 쓰기도 했습니다.

## 데모와 화제의 테스트

- 우주 슈팅 3D 게임, 공공 데이터 기반 뉴욕 지하철 실시간 지도
- Gemma 4 소형 모델을 자연어→SQL 변환용으로 파인튜닝해 정확도 66.5% 향상
- **바이럴 테스트:** 지구 위 16,200개 지점이 육지인지 바다인지 텍스트만으로 맞히는 퍼즐에서 Beam은 **95.5%** 를 기록했습니다. Claude Opus 5(92.5%)보다 높고, Claude Fable 5(97.8%)보다는 낮습니다.

## 냉정한 성적표

| 벤치마크 | Beam | 비교 |
|---|---|---|
| SWE-bench Verified | **80.9** | 강세 |
| GPQA Diamond | **90.5** | 강세 |
| DeepSWE | 44.4 | DeepSeek V4.1 Flash 74.2, Kimi K3 68, GLM 5.3 61 (GLM 5.2와 비슷) |
| Humanity's Last Exam | 36.2 | Kimi K3 46.9 |
| SciCode | 49.7 | GLM 5.3 59.0 |

LongBench와 IFBench에서는 Qwen 3.8 Max가 앞섭니다. Reflection 스스로도 Kimi K3가 더 강하다고 인정했습니다.
**정리하면, Beam은 중국의 이전 세대 모델을 따라잡았고 최신 세대와는 한 세대 정도 차이가 납니다.**

## 그래도 주목해야 하는 이유: 효율

- Reflection에 따르면, 어려운 추론에서 GLM 5.2와 비슷한 성능을 **생성 연산 3~4배 적게** 쓰면서 냅니다.
- 다른 모델과 크기를 비교하면 차이가 더 큽니다. Qwen 3.8 Max는 약 2조, Kimi K3는 2.8조 파라미터로 Beam의 약 5.5배입니다.
- **주의할 점:** 이 효율 수치는 "활성 파라미터 × 생성 토큰 수"만 따진 Reflection의 자체 계산입니다. 프롬프트 처리, 컨텍스트가 길어질수록 늘어나는 어텐션 비용, 메모리 대역폭 같은 실제 운영 비용은 빠져 있습니다. 그래서 실제 청구 비용이 그만큼 줄어든다는 보장은 없습니다.

## 내 PC에서 돌릴 수 있을까?

**아니요.** MoE는 계산량은 줄여주지만 메모리 사용량은 줄여주지 않습니다. 다음 토큰에 어떤 전문가가 필요할지 모르기 때문에 501B 전체가 메모리에 올라가 있어야 합니다.
4비트로 양자화해도 가중치만 약 250.5GB가 필요하고, 여기에 KV 캐시와 런타임 메모리가 추가됩니다. 결국 여러 개의 가속기가 있는 데이터센터 환경이 필요합니다. 그래도 Kimi K3(압축 체크포인트 약 1.4TB, 가속기 64개 이상 권장)보다는 훨씬 가볍습니다.

## 안전성

- 안전하게 행동하는 것만 학습한 별도 모델을 만들고, Beam이 성능 모델과 안전 모델 양쪽에서 **증류(distillation)** 로 배우게 했습니다.
- 반복적인 공격 테스트(레드팀)를 거쳤고, 미국·영국 정부 AI 안전 연구소와 테스트 중입니다. 안전성 평가 결과도 공개할 예정입니다.

## 무료 모델로 어떻게 돈을 버나

Laskin의 공식은 **"수익 잠재력 = 지능 밀도 × 컴퓨팅 규모 × 기업 신뢰"** 입니다.
모델은 무료지만 운영하려면 컴퓨팅이 필요합니다. Reflection은 모델부터 자체 데이터센터까지 전부 직접 갖추고, 초기 AWS나 Google Cloud 같은 위치를 노립니다.
핵심 고객은 중국 모델을 쓸 수 없는 기업과 정부입니다. "AI를 빌려 쓰던 기업들이 이제는 직접 소유하고 싶어 한다"는 판단입니다.

## 반전: 다음 날 유럽에서도 대형 모델 공개

바로 다음 날 프랑스 Mistral이 **Mistral Large 4("Le Chonk")** 를 공개했습니다.

- 1.05조 파라미터(52B 활성), 이미지 이해 지원, 100만 토큰 컨텍스트, 160개 이상 언어 지원
- 유럽 자체 데이터센터의 Nvidia 칩 약 3,800개로 처음부터 학습
- **사이버보안이 강점:** Artificial Analysis 사이버 지수 세계 5위권
  - 실제 취약점을 재현하고 패치하는 테스트에서 82%로 전체 모델 중 최고
  - 해킹 대회 과제 40개 중 93% 해결
  - 악성 요청 거부율과 프롬프트 인젝션 방어율(93.3%)도 높다고 주장
- 유럽 테크 기업 역대 최대인 30억 유로 투자를 유치했습니다.
- Reflection과 마찬가지로 대부분 프리뷰 버전을 자체 테스트한 수치입니다.

## 누구에게 맞을까

**Beam을 지켜볼 만한 경우**
- 중국 모델 사용이 금지된 기업·기관
- 직접 통제할 수 있는 오픈 모델로 코딩 도구나 에이전트를 만들려는 경우
- 리더보드 1위보다 작업당 비용이 중요한 경우
- 자유로운 상업용 라이선스가 필요한 경우

**맞지 않는 경우**
- 지금 당장 가장 강한 오픈 모델이 필요한 경우 (여전히 Kimi K3)
- 이미지 이해가 필요한 경우
- 개인 PC에서 돌리려는 경우

## 마무리

Reflection은 다음 모델을 이미 학습 중이고, 2027년에는 더 큰 모델도 계획하고 있습니다.
Beam이 실제 비용이나 속도, 그리고 학습 방식이 정답인지까지 증명한 건 아닙니다. 다만 AI 경쟁의 질문이 바뀌고 있다는 건 보여줍니다.

- **예전 질문:** "인터넷에서 데이터를 얼마나 많이 긁어올 수 있나?"
- **새로운 질문:** "모델이 어려운 환경에서 시도하고, 실패하고, 고치는 과정을 수백만 번 반복하면 어떻게 되나?"

원문은 이런 질문으로 끝납니다. **"모델이 더 적은 단어로 정답에 도달하도록 학습된다면, 토큰 단위로 요금을 받는 업계는 언제까지 지금 방식을 유지할 수 있을까?"**
